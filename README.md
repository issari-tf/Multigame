# About Multigame
Multigame is a SourceMod plugin for the community servers that want to host multiple Team Fortress 2 community gamemodes. This plugin allows customising gamemodes through a configuration file. It is designed to be:
* **Highly Configurable.** Configure the gamemode maps and map settings.
* **Can be enhanced through subplugins.** Use or develop subplugins.
* **Alternative to**
  * MapChooser.
  * NextMap.
  * RockTheVote
  * RandomCycle.
  * Nominations.

Multigame has subplugins that add features to your servers:
* **MultiMaps:** Allows players to nominate their favourite maps.
* **MultiVotes:** Allows players to vote to change gamemodes or maps.



# Installation
### Requirements
* Source Dedicated Server for Team Fortress 2.
* SourceMod: 1.10


1) Download the Release / Package from github.
2) Drag `multigame.smx` into your servers `addons/sourcemod/plugins` path.
3) Drag `multigame.cfg` configuration file into `addons/sourcemod/configs` path and customise it.
4) Restart server or change map and enjoy.
